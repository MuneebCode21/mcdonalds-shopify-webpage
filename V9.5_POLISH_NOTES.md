# KINETIQ V9.5 Polish Update

This package keeps the existing V9 theme structure and the previous `assets/kinetiq.css` / product-form fixes.

## Included

- Homepage 01–10 vertical section navigator with active-section tracking.
- Cinematic hero fallback motion (slow push/float) so the hero already feels alive.
- Optional true hero background video through the Hero section's `Background video` setting; the video is configured for autoplay, loop, muted, inline playback and no controls.
- Compact desktop nav panels that open directly beneath NEW / MEN / WOMEN / RUN / TRAIN / LIFESTYLE / SALE.
- More tactile nav buttons with active states and animated indicators.
- Collection sort dropdown styling fixed for dark UI, including readable options and persistent selected sort state after reload.
- Mobile drawer collection links corrected to point to the corresponding collection handles.

## Hero video

In Shopify Theme Editor:

Online Store → Themes → Customize → Home page → Cinematic Hero → Background video

Select/upload an MP4 or WebM. No sound is used by the theme. Leaving it empty keeps the animated image fallback.
